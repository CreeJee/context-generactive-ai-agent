# Map·Set 사용처 검토 (2026-10-06)

`apps`, `packages`, `tools`의 커밋 대상 JavaScript/TypeScript 파일을 AST로 확인했다. 문자열에 들어간 테스트 예제는 실제 생성식에서 제외했다. 의존성·생성 산출물·스킬 문서 예제는 범위 밖이다. 아래는 커밋 대상의 수정 후 줄 번호다. 기존 미커밋 작업은 별도로 검토했으며 이 커밋의 생성식 집계에서는 제외했다.

- 실제 생성식: 322개 (132개 파일), Map 143개 / Set 179개.
- 기준: 화면의 서버 배열 복제 제거, 비동기 대기는 Deferred/scope, 요청 레지스트리는 Ref<HashMap>, 실행 작업은 FiberMap, 상태는 단일 소유자. 공유 scope 자원의 획득·반납에는 RcMap을 사용하며, 일회성 응답 상관관계에는 Ref<HashMap>을 사용한다. 상수 조회·지역 인덱스·순수 멤버십·자원 조회·좁은 SDK/Node 입출력 경계는 유지.
- `delivered-messages.ts`의 두 Set 생성식은 제거해 배열에서 직접 대조한다.

## Effect 진단 범위와 경계

- `memory-agent`와 앱의 새 Effect 진단을 함께 검사했다. 조건식은 null/undefined·빈 문자열·0/NaN 처리와 타입 좁히기를 보존하며 명시적인 boolean으로 변경했다. Schema 클래스 생성은 `.make`로, 서비스 key는 파일/선언에 대응하는 결정적 key로 통일했다.
- Effect 내부 시간 조회는 Clock/DateTime으로 변경했다. SDK의 동기 콜백은 소유자의 Clock을 캡처하며, Effect 밖의 native timestamp 경계는 DateTime의 명시적인 unsafe API를 사용한다.
- 메모리 해석의 deadline은 scoped AbortController와 Effect timeout, 센서 HTTP 대기는 scoped AbortSignal과 timeout, RRSI 주기 검사는 Schedule/scoped fibers, 외부 에이전트의 stream 전달은 Queue로 관리한다. HTTP 응답 body를 읽는 동안에도 중단 신호가 살아 있게 한다.
- Vitest의 Promise callback·native mock/fixture·동기 codec 검증, React/query의 브라우저 API는 경계 예외다. 앱 AGENTS.md는 React UI를 Effect 적용 범위에서 제외한다. 테스트 파일은 해당 rule만 파일 범위로, 운영 코드는 해당 Node/SDK/동기 codec/고정 인자 API 위치만 다음 줄 범위로 이유와 함께 선언했다. 공개 application 함수에 사용하지 않는 data-last API를 추가하지 않았다.
- severity 설정과 실패 종료 코드는 유지했다. typed failure·취소·resource scope·Effect 내부 구성에 관한 오류 규칙도 유지했다. 경계 선언은 전환 완료를 뜻하지 않으며, 현재 native SDK/Node 계약을 검토할 위치를 명시한다.
